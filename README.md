# 泰迪杯A题 - 秦直道路线规划

> **2025年泰迪杯数据挖掘挑战赛 - A题**
> 
> 基于历史地理数据的"秦直道"最优路线规划与分析

## 📋 项目概述

本项目针对秦直道（秦始皇时期修建的军事交通要道）进行路线规划与分析，包含四个子问题：

1. **问题1** - 数据预处理与探索性分析
2. **问题2** - 特征分析与主成分分析
3. **问题3** - 基于代价面的最优路线规划
4. **问题4** - 沿线设施规划与优化

- 大型原始数据文件（`.tif` 高程数据、`高程数据.csv` 等）未包含在仓库中
